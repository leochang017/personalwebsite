# Editorial mode — imitate leoparpeix.com as closely as possible

Reference screenshots: `docs/ref/parpeix/*.jpeg` (home at 900px scroll stops: `home-0XXXX.jpeg`; `parpeix-about-*.jpeg`; `parpeix-playground-*.jpeg`; `parpeix-home-w5/w6` = footer; `parpeix-home-hover` = "CLICK — TO ENABLE SOUND" pill; `parpeix-home-dots` = sound toggle bars). Full page copy: `docs/ref/parpeix/parpeix-home.txt`, `parpeix-about.txt`, `parpeix-playground.txt`. **Look at every screenshot before writing code.**

The original is Vite + Vue 3 + Three.js + GSAP + Lenis + Howler (we use the same stack). It is an Awwwards Site of the Day. We reproduce the layout, type scale, rhythm, interactions, and motion with **Leo's content** from `src/content/leo.ts`. We do not copy their code, fonts, 3D models, or images.

## Tokens (from their CSS)

- Background `#f7f7f7`; ink/green text `#022016`; deep green surface `#083d2a`; pink on green `#eed6c8`; yellow `#f6e016`; light grey `#ececec`.
- Title font: `var(--font-title)` (Archivo, variable) with `font-variation-settings: "wght" 622`, `font-stretch: 92%`, uppercase, `line-height: .9`, `letter-spacing: -0.01em`. Giant titles are `font-size: 11.25vw` (max 324px, min 48px).
- Body font: `var(--font-body)` (Instrument Sans), 16px base; small UI text `clamp(12px, .97vw, 28px)`; section heads `2.36vw` (max 68px); intro statement `1.25vw`→18–36px.
- Horizontal padding `--pad-x: 2.78vw` (40px at 1440); nav top offset 2.86rem; project grid gutters 20px.
- Easing: `cubic-bezier(.6,0,.25,1)` for reveals, `power2.out` for hovers, `expo.out` for page wipes. Reveal durations 0.9–1.4s with 0.04–0.06s stagger per line/char.

## Global chrome (every page)

1. **Preloader** (`home-00900.jpeg`): a rounded, slightly rotated (−6°) card ~400×330 scales from 0.6→1 at center while a counter is implied; card contains a static image (use Leo's `/video/hero-poster.jpg` or `/images/sky-ladder.jpg`), with a tiny mark underneath. After ~1.6s the card rotates to 0, scales up to fill the viewport width, and cross-dissolves into the hero. Runs once per session (sessionStorage flag).
2. **Navbar**, fixed, 4 columns: `Leo Chang` (left) · `Student researcher, builder` (second column, starts at ~17.8% width) · right: `Work  About  Playground  ···`. Nav fades in 1s after 3.75s delay on first load. On hover each link gets an underline that draws left→right. Active link underlined. The `···` is the **sound toggle**: clicking it turns the dots into 4 animated equalizer bars (`parpeix-home-dots.jpeg`). Sound = a soft generated ambient pad using WebAudio (no files): two detuned sine oscillators through a lowpass + slow LFO, gain 0.05. Store state in `useModeStore().soundOn`. On very first pointer move over the page before the user has clicked, a **yellow pill** `CLICK — TO ENABLE SOUND` follows the cursor (position lerp 0.12, text size 11px uppercase, pill `#f6e016`, padding 8px 14px, radius 999px); it disappears after the first click anywhere.
3. **Lenis** smooth scroll (lerp 0.1, wheelMultiplier 1), integrated with GSAP ticker + ScrollTrigger.scrollerProxy.
4. **Page transitions** (vue-router `name` changes): outgoing page slides up 8% + fades; a `#022016` panel wipes bottom→top (0.9s expo.inOut), then reveals the new page sliding in from 4% below. Scroll resets while covered.
5. **Companion** (their 3D bee): a small 3D **paper crane** (built from Three.js primitives: a folded-looking body from two scaled tetrahedra/cones, two flat wings that flap with a sine, color `#f7f7f7` with `#022016` edges via EdgesGeometry) that follows the cursor with spring lag (position lerp 0.08, banking rotation from velocity), with a soft blurred shadow blob (a flat circle sprite, opacity 0.25) that lags more and sits lower-right. Rendered on a transparent fullscreen `<canvas>` with `position: fixed; pointer-events: none; z-index: 50`. Lives inside the hero/title blocks only (fades in when the block is in view). **Click anywhere on a title block** (the “(Click to feed the bee)” affordance → ours reads **“(Click to feed the crane)”**): the crane does a little loop, and a speech label (12px, uppercase, pill border 1px `#022016`) appears near it with a random line from `companionLines`; label fades after 2.2s. Small crane scale on mobile; disable on `pointer: coarse` (show nothing).
6. **Footer** (`parpeix-home-w5.jpeg`): giant centered green title, 3 lines, font-size 8.2vw: `LET'S BUILD` / `SOMETHING` / `WORTH KEEPING`. Over it a **ping-pong toy**: an orange ball (#ff5a1f, 34px) bounces inside the footer area with simple physics (gravity 0, velocity ~6px/frame, wall bounces); the cursor is a grey paddle sprite (CSS-drawn rounded rect + handle, 70px) and hitting the ball with the paddle reflects it and adds spin; implemented on a 2D canvas overlaying the footer. Bottom row (14px): `Credits` (left, opens a modal) · center `Instagram • leochang017@gmail.com • GitHub` with 6px dot separators · `© 2026` right. **Credits modal**: full-screen `#083d2a` panel sliding up, pink text, heading `* ABOUT THIS PORTFOLIO`, 2 paragraphs: "Built as a study of two sites I admire. The editorial mode borrows its rhythm from Léo Parpeix's portfolio; the arcade mode borrows its world from Samsy's. Everything on it is my own content." and a line about the stack (Vue 3, Three.js, GSAP, Lenis). Close with `×` top-right or Esc.
7. **Custom cursor**: default system cursor stays, but links get a small circular dot cursor-follower (10px, `#022016`) that scales to 36px with text `VIEW` when hovering project media.
8. Grain: a subtle fixed SVG-noise overlay at 4% opacity, `mix-blend-mode: multiply`.
9. Mobile (<800px): titles 48px minimum, nav collapses to `Leo Chang` + `Menu` that opens a full-screen green panel with the three links (pink, 11vw).

## Engineering notes

- Entry: `src/modes/editorial/EditorialApp.vue` (default export). Owns Lenis, the companion canvas, the navbar, transitions, and renders `HomePage.vue` / `AboutPage.vue` / `PlaygroundPage.vue` by `useRoute().name` (`home` | `about` | `work`). Use `<Transition mode="out-in">` with GSAP hooks for the wipe.
- Three.js: one `WebGLRenderer` per scene component, `antialias: true`, `setPixelRatio(Math.min(devicePixelRatio, 2))`, dispose everything in `onUnmounted`, pause the RAF when the canvas is off-screen (IntersectionObserver) and when `useModeStore().switching` is true.
- GSAP: `gsap.registerPlugin(ScrollTrigger)`; kill all ScrollTriggers on page unmount; `ScrollTrigger.refresh()` after images load.
- Text splitting: write a small `splitLines(el)` / `splitChars(el)` util (wrap words in spans, measure offsetTop to group lines, wrap lines in overflow-hidden masks). No SplitText plugin (paid).
- Respect `prefers-reduced-motion`: skip the preloader card motion, cycling titles become static, crane hidden.
- No external images, fonts, or code from the reference site. Fonts come from `index.html` (Archivo, Instrument Sans, JetBrains Mono).
- TypeScript strict; `npm run build` (vue-tsc + vite) must pass with zero errors.
- Do not edit: `src/content/leo.ts`, `src/stores/mode.ts`, `src/router.ts`, `src/Root.vue`, `src/App.vue`, `src/main.ts`, `index.html`, `src/styles/base.css`, anything under `src/modes/arcade/`. If you need a change there, say so in your final report instead.
